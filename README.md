# ClothSwap — Clothing Exchange & Swap Marketplace

## About the Project

ClothSwap is a web-based clothing exchange platform developed to encourage clothing reuse, reduce textile waste, and promote sustainable fashion.

Users can browse available clothes, create and manage clothing listings, filter items by location, and request clothing exchanges.

## Features

- Browse available clothing items and view their details.
- Create, edit, and delete clothing listings.
- Filter clothing by location.
- Use a swap value calculator to view estimated clothing values.
- Submit clothing swap requests through the demo login workflow.
- Use chat and negotiation features.
- Admin panel to review and accept or reject swap requests.
- Sustainability tracker to count completed exchanges.

## Project Limitations

- This is a frontend-focused demonstration project.
- Data is stored in browser LocalStorage and is not automatically shared between different users or devices.
- The login workflow is for demonstration purposes and is not production-grade authentication.
- The sustainability tracker counts completed exchanges but does not calculate actual environmental savings.
